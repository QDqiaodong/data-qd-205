# 显微分割对象数据契约

面向显微图像数据整理者，process(data)从已分割二值mask和同尺寸intensity面生成稳定对象标签、逐对象像素来源、拓扑几何与选择后标签面。这里不做自动图像分割、识别生物类别或医疗判断，也不是图形游戏/健康应用/统计看板。

mask为1..256行等宽1..256字符01串，intensity是同尺寸0..65535整数矩阵，拒绝布尔。pixel_size=[sx,sy]为正十进制字符串（最多9位整数和6位小数），代表统一单位下像素宽高；connectivity只能整数4或8。坐标x向右y向下，0起；像素代表半开矩形[x*sx,(x+1)*sx)×[y*sy,(y+1)*sy)。

以前景连通分量为对象，按首个像素(y,x)的光栅扫描顺序从1分配label，背景0。pixels逐对象按y/x排序，不丢失被筛掉对象的源位置。bbox为整数[x0,y0,x1,y1]右下半开。面积=像素数*sx*sy，centroid按物理像素中心平均，edge_perimeter为前景像素暴露四边的精确长度和，不用对角曲线或Crofton近似；8连通对角对象仍按像素边度量。

holes对当前对象的补集计洞，其他对象视作当前对象的背景。前景4连通时背景8连通，前景8时背景4；在对象bbox外补一圈连通外部背景，内部补集分量数即洞数。总拓扑扫描预算Σ(bbox宽+2)*(bbox高+2)<=2000000，超限整体拒绝，不省略对象。

selection={min_pixels:1..65536,exclude_border:bool}。触及整图任一边界标touches_border；低于最小像素数和触边可独立触发拒绝原因。labels保留所有原标签；selected_labels只将未接受对象置0，不重新编号。objects保留所有对象及原因，sum强度/mean只使用其源像素，不包含背景。空前景合法。

没有真实文件格式导入、强度校准、跨帧跟踪、拼图接缝或分裂合并；这些后续需求可接入已有label/pixel/bbox身份。合成样例仅验证精确像素语义，无真实实验或健康数据。输入严格校验，错误抛ValueError；io.publish拒绝已有目标及链接。固定example只演示API。
